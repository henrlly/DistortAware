Detector

All endpoints must use plain HTTP loopback. The active selection is verified against the service's model contract before it is accepted.

Scan scope

Whole-page mode temporarily scrolls through the page to capture lazy-loaded rendered images, then returns to your original position. Infinite feeds stop at the image limit or a 40-viewport safety cap.
Privacy boundary The extension sends only rendered viewport crops to your loopback service. It does not send page URLs, cookies, captions, or source-image URLs, and it performs no cloud API calls. Whole-page mode scrolls locally; it does not fetch image URLs.
